# Guía para profesionales y familias

Esta guía está pensada para terapeutas ocupacionales, familiares y profesionales que quieran utilizar Apptonomia como herramienta de apoyo.

---

## ¿Para quién es Apptonomia?

Apptonomia está diseñado principalmente para:

- **Personas con discapacidad intelectual** que quieren practicar habilidades de la vida diaria
- **Familias** que buscan recursos para trabajar en casa
- **Terapeutas ocupacionales** que necesitan herramientas complementarias a la intervención directa

La aplicación **no sustituye** la intervención profesional, pero puede servir como:

- Refuerzo entre sesiones
- Práctica autónoma en el hogar
- Registro del progreso del usuario

---

## Cómo usar Apptonomia en terapia

### Evaluación inicial

Antes de usar la aplicación, observa al usuario con estas preguntas:

1. ¿Qué nivel de autonomía tiene en su vida diaria?
2. ¿Qué habilidades quiere trabajar? (autonomía, memoria, motricidad, etc.)
3. ¿Qué actividades le resultan atractivas o motivantes?
4. ¿Necesita apoyo para usar dispositivos tecnológicos?

### Adaptaciones

#### Nivel de dificultad

Cada actividad tiene **3 niveles** (Fácil → Medio → Difícil). Para elegir:

- **Nivel 1 (Fácil)**: Usuarios nuevos o con apoyo significativo
- **Nivel 2 (Medio)**: Usuarios con experiencia moderada
- **Nivel 3 (Difícil)**: Usuarios autónomos que buscan desafío

#### Reducciones

Si el nivel 1 sigue siendo difícil, puedes:

- Reducir el número de elementos (ej: menos cartas en Parejas)
- Aumentar el apoyo físico para guiar el movimiento
- Usar la actividad como demostración antes de pedir autonomía

## Seguimiento del progreso

### Estrellas

Cada actividad guarda **estrellas** cuando se completa:

- ⭐ = 1 estrella (nivel completado)
- ⭐⭐ = 2 estrellas (varios niveles)
- ⭐⭐⭐ = 3 estrellas (todos los niveles)

Para ver el progreso:

1. Accede a la configuración escribiendo `/ajustes` al final de la URL
2. Consulta "Mi progreso" para ver un resumen

### Registro manual

Para un seguimiento más detallado, puedes usar esta plantilla:

```
Fecha: _______________
Usuario: _______________
Actividad: _______________
Nivel usado: _______________
Observaciones:
___________________________________
___________________________________
Apoyos necesarios:
___________________________________
```

## Recomendaciones de uso

### Frecuencia

| Objetivo | Frecuencia recomendada |
|---------|------------------------|
| Mantenimiento | 2-3 veces por semana |
| Mejora de habilidades | Diario o casi diario |
| Introducción de nuevas actividades | 3-4 veces por semana |

### Duración

- **Sesiones cortas**: 10-15 minutos para usuarios nuevos
- **Sesiones medias**: 20-30 minutos para usuarios intermedios
- **Sesiones largas**: 30-45 minutos para usuarios avanzados

### Pautas para familiares

Si eres familiar y trabajas con Apptonomia en casa:

1. **No corrijas continuamente**: deja que el usuario explore y falle sin presión
2. **Celebra los intentos**: no solo los aciertos
3. **Sigue su interés**: si una actividad le motiva, úsala más
4. **Respeta el ritmo**: no fuerces si el usuario está cansado o frustrado
5. **Comunica con el terapeuta**: comparte qué funciona y qué no

## Seguridad y privacidad

### Datos

- **No se recogen datos personales**: la aplicación no pide registro
- **El progreso se guarda localmente**: solo en el dispositivo usado
- **Sin conexión a internet necesaria**: funciona offline

### Contenido sensible

Algunas actividades tratan temas delicados:

| Actividad | Tema | Recomendación |
|-----------|------|---------------|
| **Emergencias** | 112, situaciones de peligro | Revisar primero, acompañar si es necesario |
| **Teléfonos Importantes** | 112, situaciones de peligro | Revisar primero, acompañar si es necesario |
| **Chat Seguro** | Manipulación online | Adecuado para mayores de edad o con supervisión |
| **Chat Acoso** | Acoso entre iguales | Siempre con supervisión profesional |

## Resolver problemas comunes

### El usuario se frustra

1. Cambia a una actividad más fácil
2. Reduce el nivel de dificultad
3. Usa el botón de "Volver" para salir
4. Vuelve otro día

### La actividad es demasiado fácil

1. Sube al siguiente nivel
2. Introduce una actividad nueva
3. Deja que decida cuándo repetir o cambiar de actividad

### No funciona el audio

1. Comprueba el volumen del dispositivo
2. Comprueba los permisos del navegador
3. Prueba con otro navegador (Chrome o Firefox)
